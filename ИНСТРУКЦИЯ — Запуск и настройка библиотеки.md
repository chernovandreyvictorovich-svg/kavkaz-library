## 1. Что входит в поставку

Вам передана папка со следующей структурой:

```
КАВКАЗ суды ГВС\
├── 12. КАВКАЗ\               ← Документы библиотеки (PDF, DOCX)
│   ├── 1. Порядок прохождения военной службы\
│   ├── 2. Порядок обеспечения денежным довольствием\
│   ├── ... (всего 14+ разделов)
│   └── 14. Бюллетень\
│       ├── Обзоры практики Кассационного военного суда\
│       └── Обзоры суд. практики Верховного Суда РФ\
│
└── portal\                   ← Программа-сервер
    ├── server.js
    ├── package.json
    └── public\
        ├── index.html
        └── stats.html
```

**Папку `12. КАВКАЗ`** можно хранить в любом удобном месте (см. раздел 10).
**Папка `portal`** — это программа, её перемещать не нужно.

## 2. Требования к компьютеру

| Требование | Минимум |
|---|---|
| Операционная система | Windows 10 / Windows 11 |
| Оперативная память | 2 ГБ свободных |
| Место на диске | зависит от документов + ~100 МБ для программы |
| Сеть | **не требуется** — портал работает полностью офлайн |
| Браузер | Google Chrome, Microsoft Edge или Firefox (последние версии) |

## 3. Установка Node.js

Node.js — это среда выполнения, необходимая для работы программы.

### Шаг 1. Скачать установщик

Перейдите на сайт **https://nodejs.org** и нажмите кнопку **«LTS»** (рекомендуемая версия).

> Если компьютер не подключён к интернету, попросите системного администратора скачать установщик заранее и передать на флешке.

### Шаг 2. Установить

Запустите скачанный файл (`node-v##.##.#-x64.msi`) и нажимайте **«Next»** на каждом шаге. Все настройки оставьте по умолчанию.

### Шаг 3. Проверить установку

1. Нажмите `Win + R`, введите `cmd`, нажмите Enter
2. В открывшемся окне введите:
   ```
   node --version
   ```
3. Должна появиться строка вида `v22.x.x` — Node.js установлен

### Шаг 4. Установить зависимости программы

1. В том же окне командной строки перейдите в папку `portal`:
   ```
   cd "D:\КАВКАЗ суды ГВС\portal"
   ```
   *(путь замените на фактический)*
2. Введите команду:
   ```
   npm install
   ```
3. Дождитесь завершения (появится строка вида `added 60 packages`). Интернет нужен **только в этот момент**. После установки библиотека работает офлайн.

> **Важно:** команду `npm install` нужно выполнить **один раз** при первой установке.

## 4. Первый запуск

### Запуск сервера

1. Нажмите `Win + R`, введите `cmd`, нажмите Enter
2. Перейдите в папку portal:
   ```
   cd "D:\КАВКАЗ суды ГВС\portal"
   ```
3. Запустите сервер:
   ```
   node server.js
   ```
4. В окне появится сообщение:
   ```
   📚 Библиотека КАВКАЗ → http://localhost:3001
      Папка: D:\КАВКАЗ суды ГВС\12. КАВКАЗ
   ```

**Это окно командной строки нужно оставить открытым** — пока оно открыто, портал работает.

### Открытие в браузере

Откройте браузер и перейдите по адресу:

```
http://localhost:3001
```

Откроется главная страница библиотеки.

## 5. Настройка пароля администратора

При первом открытии портал предложит установить пароль администратора — он нужен для загрузки новых документов и просмотра аналитики.

1. В браузере на главной странице нажмите кнопку **«Войти»** (правый верхний угол)
2. Появится поле для ввода пароля и кнопка **«Установить пароль»**
3. Введите пароль (минимум 6 символов) и нажмите кнопку
4. Запишите пароль — восстановить его нельзя, только сбросить вручную

> **Если забыли пароль:** удалите файл `portal\config.json` — при следующем запуске сервера пароль можно будет установить заново. Все документы при этом сохраняются.

## 6. Настройка автозапуска (PM2)

PM2 — менеджер процессов, который держит сервер постоянно включённым: автоматически запускает его при старте Windows и перезапускает при сбоях. После настройки открывать командную строку вручную не нужно.

### Установка (один раз)

1. Открыть командную строку от имени администратора (`Win + R` → `cmd`, правой кнопкой → «Запуск от имени администратора»)

2. Установить PM2:
   ```
   npm install -g pm2 pm2-windows-startup
   ```

3. Перейти в папку portal:
   ```
   cd "D:\КАВКАЗ суды ГВС\portal"
   ```

4. Запустить сервер через PM2:
   ```
   pm2 start server.js --name kavkaz-library
   ```

5. Сохранить список процессов:
   ```
   pm2 save
   ```

6. Настроить автозапуск при старте Windows:
   ```
   pm2-startup install
   ```

7. Готово. Закройте командную строку — сервер продолжает работать в фоне.

### Управление PM2

| Действие | Команда |
|---|---|
| Статус сервера | `pm2 status` |
| Перезапустить | `pm2 restart kavkaz-library` |
| Остановить | `pm2 stop kavkaz-library` |
| Запустить снова | `pm2 start kavkaz-library` |
| Просмотр логов | `pm2 logs kavkaz-library` |

## 7. Доступ с других компьютеров сети

Чтобы сотрудники могли открывать библиотеку со своих рабочих мест:

### На компьютере-сервере

1. Узнайте IP-адрес сервера: `Win + R` → `cmd` → введите `ipconfig`
2. Найдите строку **«IPv4-адрес»** (например: `192.168.1.100`)
3. При необходимости разрешите порт 3001 в брандмауэре Windows:
   - Открыть «Брандмауэр Защитника Windows» → «Дополнительные параметры»
   - «Правила для входящих подключений» → «Создать правило»
   - Тип: Порт → TCP → Порт: 3001 → Разрешить → Имя: «Библиотека КАВКАЗ»

### Ярлык для пользователей сети

Создайте файл `Библиотека КАВКАЗ.url` со следующим содержимым и разошлите сотрудникам (или разместите в общей сетевой папке):

```
[InternetShortcut]
URL=http://192.168.1.100:3001
```

*(замените `192.168.1.100` на реальный IP сервера)*

Двойной клик по этому файлу откроет библиотеку в браузере. Его можно скопировать на рабочий стол.

## 8. Получение обновлений

Библиотека подключена к репозиторию GitHub. Когда разработчик добавляет новые документы или обновляет программу, они попадают туда. Получить их можно одним кликом.

### Условия работы обновления

- На компьютере-сервере должен быть установлен **Git** (бесплатно: https://git-scm.com)
- В Git-репозитории библиотеки должны быть настроены учётные данные (разработчик настраивает при первоначальной установке)

### Как обновиться

1. Войти в портал как администратор
2. В правом верхнем углу нажать кнопку **«Обновить»** (значок круговой стрелки)
3. Подождать несколько секунд — появится окно с результатом
4. Если написано «Already up to date» — обновлений нет, библиотека актуальна
5. Если перечислены файлы — изменения загружены; сервер автоматически перезапустится через 1 секунду

> **Важно:** если сервер управляется через PM2, после обновления программы он перезапустится автоматически. Если PM2 не настроен — перезапустите сервер вручную (раздел 11).

## 9. Добавление документов

### Через браузер (рекомендуется)

1. Войти как администратор
2. Перейти в нужный раздел
3. Нажать кнопку **«Загрузить»** (появляется после входа)
4. Выбрать файлы (PDF, DOCX, DOC — до 200 МБ каждый)
5. Нажать **«Загрузить»**

### Напрямую через файловую систему

Просто скопируйте нужные файлы в соответствующую подпапку внутри `12. КАВКАЗ`. Изменения появятся в портале немедленно — перезапуск не нужен.

### Создание нового раздела

Создайте новую папку внутри `12. КАВКАЗ`. Нумерацию можно продолжить (15, 16...) или дать произвольное название.

## 10. Аналитика использования

Портал автоматически записывает, что ищут пользователи и какие документы открывают.

Чтобы посмотреть статистику:
1. Войти как администратор
2. Нажать кнопку **«Аналитика»** в верхнем правом углу
3. Откроется страница со статистикой:
   - Популярные поисковые запросы
   - Запросы без результатов (показывает, каких документов не хватает)
   - Самые открываемые документы
   - График активности по дням

Данные хранятся в файлах `portal\data\searches.ndjson` и `portal\data\opens.ndjson`.

## 11. Ежедневная работа (если PM2 не настроен)

Если PM2 не установлен, сервер нужно запускать вручную:

1. Открыть командную строку (`Win + R` → `cmd`)
2. Ввести:
   ```
   cd "D:\КАВКАЗ суды ГВС\portal"
   node server.js
   ```
3. Оставить окно открытым — пока оно открыто, сервер работает

Для остановки — закрыть окно командной строки.

## 12. Часто задаваемые вопросы

**Можно ли хранить документы на сетевом диске или NAS?**

Да. При запуске сервера укажите путь через переменную окружения:
```
set LIBRARY_PATH=\\сервер\ресурс\12. КАВКАЗ
node server.js
```

**Можно ли изменить порт (если 3001 занят)?**

Да:
```
set PORT=8080
node server.js
```
После этого открывать: `http://localhost:8080`

**Как обновить документы без перезапуска сервера?**

Просто добавьте или замените файлы в папке `12. КАВКАЗ` напрямую. Изменения видны сразу.

**Открывается ли файл .doc (старый формат Word)?**

DOC-файлы открываются через встроенный просмотрщик Word Online или предлагают скачать. DOCX открываются прямо в браузере. PDF открываются inline.

**Как перенести библиотеку на другой компьютер?**

1. Скопируйте всю папку `КАВКАЗ суды ГВС\` на новый компьютер
2. Установите Node.js (раздел 3)
3. Выполните `npm install` в папке `portal\`
4. Удалите `portal\config.json` и установите новый пароль
5. Настройте PM2 заново (раздел 6)

**Сервер упал или завис — что делать?**

Если PM2 настроен — он перезапустит сервер автоматически. Если нет:
```
cd "D:\КАВКАЗ суды ГВС\portal"
pm2 restart kavkaz-library
```
Или просто: `pm2 restart kavkaz-library` из любой папки.
