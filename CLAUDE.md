# КАВКАЗ суды ГВС — контекст проекта для ИИ-ассистента

## Что это

Внутренняя библиотека судебной практики для военных судов Кавказского региона.
Два компонента:
- **`12. КАВКАЗ/`** — папка с документами (PDF, DOCX, DOC). Это и есть сама библиотека, она передаётся в суд.
- **`portal/`** — веб-портал (Node.js/Express), который отдаёт документы через браузер.

## Структура документов (`12. КАВКАЗ/`)

Папки пронумерованы (1–14+), каждая — раздел практики:
```
1. Порядок прохождения военной службы
2. Порядок обеспечения денежным довольствием
3. Право на жильё
4. Дисциплинарная ответственность
5. Материальная ответственность
6. Дела, связанные с государственной тайной
7. Компенсация за нарушение права... (Гл. 26 КАС РФ)
8. Другие категории исков (моральный вред, индексация)
9. Процессуальные вопросы. ГПК РФ
10. Процессуальные вопросы. КАС РФ
11. Федеральная государственная служба
12. Неосновательное обогащение
13. КоАП РФ
14. Бюллетень
    └── Обзоры практики Кассационного военного суда  ← квартальные обзоры КВС
    └── Обзоры суд. практики Верховного Суда РФ       ← полные обзоры ВС РФ
    └── Сроки давности / исковой давности / обращения в суд
```

Соглашение об именах файлов:
- Обзоры ВС РФ: `Обзор № X (год) ВС РФ.pdf`
- Обзоры КВС: `Обзор № X (год) КВС.pdf`

Важно: КВС (Кассационный военный суд) создан 01.10.2019. Обзоры до этой даты — только ВС РФ.

## Технический стек портала (`portal/`)

| Компонент | Решение |
|---|---|
| Сервер | Node.js + Express |
| Аутентификация | JWT (bcryptjs для хеша пароля) |
| Загрузка файлов | multer |
| DOCX → HTML | mammoth (server-side, без интернета) |
| Аналитика | NDJSON-файлы в `portal/data/` |
| БД | **нет** — всё на файловой системе |

## Ключевые файлы портала

```
portal/
├── server.js          # Весь серверный код (Express API + статика)
├── package.json
├── config.json        # Хеш пароля + JWT-секрет (генерируется при первом запуске)
├── data/
│   ├── searches.ndjson  # Лог поисковых запросов
│   └── opens.ndjson     # Лог открытий файлов
└── public/
    ├── index.html       # Главная страница библиотеки
    └── stats.html       # Дашборд аналитики (только для администратора)
```

## API-маршруты (server.js)

| Метод | Путь | Доступ | Назначение |
|---|---|---|---|
| GET | `/api/tree` | все | Дерево папок |
| GET | `/api/files?path=` | все | Файлы в папке |
| GET | `/api/search?q=` | все | Поиск по именам файлов |
| GET | `/api/view?path=` | все | Открыть файл (PDF inline) |
| GET | `/api/docx-html?path=` | все | DOCX → HTML для просмотра |
| GET | `/api/download?path=` | все | Скачать файл |
| POST | `/api/login` | все | Вход администратора |
| POST | `/api/setup` | все (1 раз) | Первоначальный пароль |
| POST | `/api/upload` | **admin** | Загрузить файлы |
| POST | `/api/mkdir` | **admin** | Создать папку |
| POST | `/api/log/search` | все | Логировать поиск |
| POST | `/api/log/open` | все | Логировать открытие |
| GET | `/api/stats` | **admin** | Данные аналитики |

## Безопасность

- `resolveSafe()` — защита от path traversal: любой запрос за пределы `LIBRARY` отклоняется
- `requireAuth` — middleware для admin-эндпоинтов, проверяет Bearer JWT
- Библиотека (`LIBRARY`) — это `../12. КАВКАЗ` относительно `portal/`; можно переопределить через `LIBRARY_PATH` в env

## Переменные окружения

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `PORT` | `3001` | Порт HTTP-сервера |
| `LIBRARY_PATH` | `../12. КАВКАЗ` | Путь к папке с документами |

## Аналитика

Два NDJSON-файла (добавляются строки без перезаписи):
- `searches.ndjson`: `{"q":"текст запроса","n":5,"t":1729500000}` — запрос, кол-во результатов, unix timestamp
- `opens.ndjson`: `{"p":"путь/к/файлу.pdf","t":1729500000}` — путь относительно LIBRARY, timestamp

Дашборд `/stats.html` показывает: топ запросов, нулевые результаты (пробелы в библиотеке), топ документов, активность по дням.

## Рабочие процессы

### Добавить документы в библиотеку
1. Положить в папку `Документы на разбор\` (staging)
2. Попросить ИИ-ассистента: прочитай документы и разложи по разделам
3. ИИ читает каждый файл через Python (`fitz`/PyMuPDF) или Node, определяет источник (ВС РФ / КВС / другое), предлагает раздел и новое имя
4. После подтверждения — перемещает `Move-Item` с переименованием

### Создать новый раздел в библиотеке
Спросить пользователя перед созданием. Папка создаётся как подпапка `12. КАВКАЗ\`.

### Отладка сервера
```powershell
cd "D:\CLAUDE CODE\КАВКАЗ суды ГВС\portal"
node server.js
```
Логи Express выводятся в консоль. Порт по умолчанию 3001.

## Что нельзя делать без подтверждения

- Перемещать или переименовывать документы без показа плана пользователю
- Создавать новые папки в `12. КАВКАЗ\` без явного «да»
- Удалять любые файлы
- Делать git commit / push
